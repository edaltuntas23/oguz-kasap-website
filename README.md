# Oğuz Kasap Website 🥩

A responsive, multi-page website developed for **Oğuz Kasap**, a local butcher shop in Istanbul.

The website showcases the business, its products, and store information through a clean and user-friendly interface.

## Features
- Responsive web design
- Product showcase and photo gallery
- About Us and Contact pages
- Multi-page navigation

## Technologies
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

🚧 Currently under development. Further improvements and deployment are planned.
